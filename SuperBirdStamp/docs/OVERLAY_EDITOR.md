# 叠加层编辑

模板管理和主窗口的「模板叠加」区域使用同一套编辑器。点击「新增叠加层」添加自定义文本、元数据文本、Badge（徽章）、静态图像或背景。图片会内嵌到配置，原素材移动后仍可使用；相同素材在一个工作区中只保存一份。

添加「元数据文本」后，在字段中选择「鸟种拼音」，即可显示 `jiā yàn` 这样的带声调拼音，位置、字号和旋转与其它文字相同。优先读取已有的拼音元数据（XMP/文件优先于 report.db）；没有时按中文鸟名查询内置的 SuperPicky 拼音表，XMP 中修正过的鸟名优先于数据库旧名。支持约 1.14 万个鸟名，无需联网；未收录的名称按缺失字段处理。

## Badge 形状与元数据配色

「新增叠加层 → Badge（徽章）」默认引用 **GBIF 稀有度**（`gbif_rarity_100`）。Badge 在画面中央创建，按分数显示普通、少见、稀有、史诗、传奇或未知。可在「字段/占位符」选择其他元数据，或把「文字来源」改成自定义文本。`rarity_index` 是另一字段，不套用 GBIF 的 0–100 分级。

- **Badge 配色 → 自动**：引用 GBIF 稀有度或 IUCN 保护等级（`iucn_category`）时，背景色、文字色分别与 SuperViewer「设置 → 用户选项 → 稀有度徽章 / 保护等级徽章」一致，包括用户修改过的各档颜色。保护等级默认采用 Cornell / eBird 保护状态配色，未知数据独立显示。其他字段和自定义文本使用图层自己的背景色、文字色。
- **Badge 配色 → 自定义颜色**：使用此图层保存的两种颜色，不再随照片等级或徽章配置改变。切回自动再切回自定义，之前选的颜色仍保留。模板/工作区存配色模式和自定义值，不把自动解析出的颜色固化。
- **Badge 内容**：自动模式把 GBIF 分数或 IUCN 代码转为现有配置中的等级名称，也会跟随自定义名称；可选「原始字段值」显示分数或代码。文字格式与配色模式独立。
- **Badge 形状**：默认「圆角矩形」，旧模板也保持圆角矩形；可切换为「圆形」。圆形根据内容和内边距自动计算直径、居中放置文字，支持长文本及多行文字。圆形模式禁用圆角参数，切回圆角矩形时保留原圆角值。
- **内边距与圆角**：水平/垂直内边距按实际字号缩放；圆角按徽章高度计算，最高 50% 为胶囊样式。字体、描边、阴影、整体透明度、移动、缩放和旋转沿用文字图层操作。

自动配色只读同一源码目录/安装目录旁的 SuperViewer `SuperViewerUser.cfg`：源码为 `SuperViewer/SuperViewerUser.cfg`，macOS 为并列 `SuperViewer.app/Contents/MacOS/SuperViewerUser.cfg`，Windows 为并列 `SuperViewer/SuperViewerUser.cfg`，兼容同目录可执行文件布局。找不到时使用当前应用用户选项及共享内置默认值；文件格式错误会记录诊断。保存 Viewer 配色后，BirdStamp 下次刷新预览或导出时自动重读，不需要重新添加图层。改变配色也会使已有导出帧缓存失效。

Badge 与「绘制文本」开关一起控制，不依赖 Banner/图像开关。图片、GIF/视频帧以及 CLI `render --template` 使用同一圆角绘制；`--no-draw-text` 同时关闭 Badge。自动位置使用完整徽章边界对齐，不参与旧文字的字号避让；拖动转手动时保持可见尺寸和位置。旧模板没有 Badge 时不改变其排版或像素。

## 直接在画面中调整

选择「编辑叠加层」工具，或点击「在预览中编辑」。新增自定义文字和图片会在成片中央选中。

- 拖动图层移动，角手柄等比缩放，顶部圆形手柄旋转。背景另有边手柄调整宽高。
- 靠近成片边缘、中心线或其它图层时显示吸附线。Alt 临时关闭吸附，Shift 旋转按默认 15° 吸附。
- 方向键移动 1 个逻辑成片像素，Shift 加速至 10 像素；Delete/Backspace 删除未锁定图层。
- 空格加拖动平移视图；Esc 取消当前手势，再按退出编辑。
- 编辑模式内使用系统撤销/重做快捷键（macOS Command、Windows Ctrl），也可使用面板按钮。一次拖动只产生一条记录。文字输入框仍使用自己的文本编辑快捷键。

图层列表从上到下对应从前到后的绘制顺序，支持拖动排序、复制、删除、显示和锁定。旧模板的背景默认锁定，先在列表选中并解锁后再拖动。属性按「内容」「位置」「效果」分组，文字的描边、阴影随整体缩放。

所有百分比参数均提供滑动条和两位小数的数值输入，覆盖中心位置、偏移、缩放、宽高、不透明度、阴影不透明度及渐变参数。拖动即时更新预览，一次连续拖动只记一次撤销。位置、缩放和宽高优先使用常用滑动区间，输入更大或负向的合法数值时自动扩展范围；旧配置的数值范围保持不变。

图像叠加层的「内容」页可开启「自定义颜色」，通过「图像颜色」的色值、调色板或吸管把图像改为单色，适合图标、签名和水印。原图透明度和半透明边缘保留；整体透明程度仍由「位置 → 不透明度」控制。取消「自定义颜色」即可恢复原色，原素材不被修改。颜色随模板和照片实例保存，支持撤销，并应用于预览、图片/GIF/视频及 CLI 输出。

## 自动行 / 列组合

将文字、Badge 或图像拖到另一元素的左/右边，会预览一个**行组合**；拖到上/下边，会预览一个**列组合**。接近时显示绿色组合边框和“松手：组合为行 / 列”，松开鼠标才保存关系；按 Esc 或失焦可取消。只接近中心或对齐线不会自动组合，必须靠近相邻边缘。

- 同一行按实际内容宽度依次排列；列按实际内容高度排列，可选择从上到下或从下到上。中文变长、文字换行、徽章尺寸变化时重新计算，不再逐个挤开或缩小字号。
- 已有垂直组合时，拖到其中某个元素的左/右侧即可把该项变成嵌套的水平行，外层列及其它行保持原有顺序；已有水平行则直接插入。同样接近时优先该行，不让整列外框抢走吸附目标。
- 行可以嵌入列。按住 **Command / Ctrl 拖动整组**，把一行拖到另一行的上/下边即可组成列；也可拖动整组到独立元素旁。macOS 使用 Command，Windows 使用 Ctrl。绿色外框表示当前最外层组合。
- 普通拖动组合成员可移出、插入或重新排序；**Alt 拖动**强制移出并暂时关闭吸附。Command/Ctrl + Alt 平移整组且不吸附。方向键移动整个最外层组合，Shift 加速。
- 「布局」页选择“所在组合”或“外层组合”，调整排列方向、间距及交叉方向对齐。行的交叉方向为上/中/下，列为左/中/右。间距按成片短边的百分比计算，设为 **0** 即可贴在一起。
- “整组固定边”选择九宫格锚点：例如下左固定时，内容增加会向右、向上扩展。向下排列切换为顶部固定，向上排列切换为底部固定；嵌套组合的位置由外层管理。组合首次创建时按画面所在区域选择固定边。
- “移出组合”保留该元素当前可见位置；“解散此组合”保留独立后的可见位置，已有子行仍保持组合。解散嵌套组合时，其成员提升到父组合。所有操作均支持撤销/重做。
- 隐藏元素、空字段不占位置或间距；旋转、描边、阴影、徽章内边距均计入实际边界。布局顺序独立于图层前后顺序，列表拖动仍只调整绘制层级。背景不加入组合。

「布局」页默认收起精确坐标，独立元素可展开“精确位置 / 兼容设置”；组合成员的位置由组合管理，不能再用单个 X/Y 与之冲突。旧模板在未组合的部分仍保留旧版对齐/避让，打开时不自动改写；首次拖动会保持当前可见字号。超出画幅的内容仍按画幅裁剪，不自动换行或缩字；可减小字号、缩放、间距或移动整个组合。

A/B 下只编辑 B 的当前照片；进入编辑会停止播放，显示 B 的模板成片。焦点框、鸟体框、构图线和去抖动参考区沿用各自工具，编辑手柄和吸附线不进入导出。

## 模板与照片实例

模板管理器左侧列表支持右键定位模板 JSON：macOS 在 Finder 中选中文件，Windows 在资源管理器中选中文件，Linux 打开所在文件夹。操作针对右键点击的模板；悬停模板名可查看完整路径。文件被外部移动/删除或系统文件管理器启动失败时显示提示。

未编辑的照片跟随模板。首次编辑后，整套叠加层成为该照片的独立配置，原模板之后的更改不会覆盖它；元数据文字仍从对应照片取值。

「恢复模板」取消独立配置。「应用到选中」「应用到全部」只复制叠加层，不改裁切。「另存模板」把当前图层和模板其它设置保存为一个可复用模板。裁切区域现有的「全部应用」也会复制叠加层。

旧模板可直接读取，不会仅因打开而改写。实际编辑保存后使用版本化的 `overlays` 格式。工作区和模板采用 UTF-8 JSON 与原子保存；撤销历史和选框是会话状态，不写入配置。字体沿用现有的系统字体回退规则。

## 实现入口与验证

- `birdstamp/overlays/model.py`：旧字段/Banner 适配、规范化、实例优先级和工作区素材去重。
- `birdstamp/overlays/badge.py`：无窗口的圆角绘制、GBIF 等级解析与 Viewer 配色读取。
- `birdstamp/overlays/assets.py`：静态素材导入、内容哈希验证和 128 MiB 解码缓存。
- `birdstamp/overlays/layout.py`：`overlay_layouts` 树的规范化、真实边界布局、邻边吸附、组合/移出及独立位置保留。节点保存有序 `children`、`direction`（row/down/up）、`gap`（短边比例）、`align`、锚点位置与固定边；重复归属和循环嵌套会拒绝加载。空组合随删除清理，单成员组合保留原锚点。
- `birdstamp/overlays/render.py`：逻辑画幅布局、旋转命中几何和 Pillow 合成，不依赖窗口状态。
- `gui/overlay_panel.py`、`gui/overlay_edit.py`、`gui/editor_overlays.py`：共用属性编辑、手势会话和主窗口绑定。拖动只更新有界预览，松手后提交配置；切图清理旧场景，异步素材导入按上下文代次接收。
- `render_template_overlay()`、模板叠加管线阶段、图片/GIF/视频均使用同一核心。CLI `render --template 模板.json` 支持新格式，`--no-draw-images` 可单独关闭图像图层。

Badge 默认值（`overlay_badge`）、新建字号、图片默认宽度、吸附距离、旋转步长和交互预览尺寸从 `config/editor_options.json` 读取。回归入口为 `tests/test_overlay_badge.py`、`tests/test_overlay_layers.py` 和 `tests/test_overlay_editor.py`，并继续覆盖旧模板、文字效果、裁切坐标、工作区及预览模式测试。

布局组合随模板、照片覆盖和工作区完整保存，CLI `render --template`、图片/GIF/视频自动使用同一渲染核心，无需新增导出参数。`editor_options.json` 的 `overlay_layout_snap_distance` 默认为 12 个视口逻辑像素（不随缩放/DPI 改变手感），`overlay_layout_gap_pct` 默认为 0.6%。回归见 `tests/test_overlay_layout.py`，覆盖动态中文、空/隐藏、旋转效果、嵌套/双向生长、拖动预览/取消/撤销、持久化及 CLI/管线一致性。
