# 独立去抖动流程

## 操作

1. 在“导出”组切到“去抖动”标签页，选择参考照片。右侧 **编辑构图 / 成片预览** 使用与左侧一致的原生 Tab 切换，选中项保持高亮。
2. 在编辑构图下点击“框选 / 追加选区”，在原图上圈出稳定纹理；Shift 追加多个区域。八个手柄调整四边、四角。**只需在这一张参考图框选一次，后续照片自动匹配，不需要逐张添加。**参考照片由首次框选确定，切图不会重设。
3. 删除选区：右键框内删除该区（重叠时删除最上层）；空白处右键不删除。也可在页内选区列表多选，再点“删除选中选区”。工具栏“清除参考区”仍可清空全部。
4. 点击 **分析并预览成片**。无需设置裁切比例，“不裁切”同样可用。后台逐图对齐参考区，自动计算整组共同覆盖的最大矩形，默认输出尺寸相同、没有补边。可选 **补边保留完整画面（供二次裁切）**：改用全部对齐画面的并集，缺失区域补黑，完整保留每张原图，方便导出后二次裁切。面板显示实际输出像素尺寸；修改此选项需重新分析。
5. 使用成片下方的“播放序列 / 暂停”、上一张 / 下一张或缩略图条检查整组，可调 1–30 帧/秒并选择循环。参考帧、部分选区失配帧在缩略图条标记；当前匹配详情在左侧分析按钮下显示。照片列表、缩略图条与画布同步。分析后，照片列表与成片预览共用方向键：← / ↑ 上一张，→ / ↓ 下一张。点击画布、播放/翻页按钮、缩略图条或成片页签获得焦点后均可操作；按住连续显示缓存小图，物理松键后只为最终一张升级清晰预览，失焦停止。帧率等输入控件保留原生方向键行为，A 图对照不触发 B 图切换。编辑构图和成片预览都显示原编号跟踪框：黄色表示成功；红色虚线表示未匹配的预计位置，全部失配时标为“未定位”，不冒充实际匹配。画面外的区域显示编号提示，具体原因可在分析信息上悬停查看。目标照片的跟踪框只读，修改需返回参考照片。参考线、焦点、鸟体框与原工具栏开关共用，辅助显示不写入输出。工具栏“自动焦点居中”可将当前画面里的焦点保持在视口中央（隐藏焦点框也可用），无焦点时使用图像中心；放大和连续切图保持锁定，关闭后恢复自由拖动。该选项仅影响观看位置，不改变实际对齐结果。
6. 需要双图检查时，打开预览区的 **A/B 对照**。A 默认选择参考图并“钉住”；用 A 的选图框可主动换图，取消钉住后随 B 切换。B 的选图框与照片列表同步，保留当前编辑上下文。A 可独立选择原图或已分析的去抖动成片；在 B 编辑构图、成片预览、导出设置之间切换都不会改掉 A 的照片或视图。两侧独立缩放、拖动和适应窗口，A 另有自动焦点居中开关。参考区编辑仍在 B 完成。A/B 只影响观看，不改变选区、分析、裁切或输出。
7. 选择本页的 PNG / JPG，点击 **去抖动导出全部** 并选择保存目录。后台将整个照片列表写到新建的“去抖动_…”子目录，按列表顺序编号，避免同名图片冲突。不覆盖原图或已有输出。每张 PNG/JPG 都嵌入原图 EXIF（含厂商私有数据），只校正方向、成片尺寸和缩略图。原图旁同名 `.xmp` / `.XMP` 按输出图片的新文件名原样复制，例如 `DSC08647.xmp` → `0001_DSC08647.xmp`；没有 sidecar 时不生成空文件。

这是一条独立的原图处理流程，**不读取前面流程的模板、手动裁切、留边、尺寸限制或文字叠加**。返回“导出设置”仍可按原流程导出；普通图片/GIF/视频导出不自动消费本页的参考对齐计划。旧“批量构图 / 构图平滑”选项及统一自动裁切、中位中心平滑计算已移除；旧工作区字段会忽略，普通导出按各图自身构图处理。

导出直接复用整组分析后的裁切坐标，不重复匹配参考区；原分辨率图片仍需读取、裁切、编码并保存 EXIF。按 CPU 和可用内存自动并行处理，进度显示并行上限；快速/清晰预览缓存经过缩小，不会替代原分辨率输出。PNG 使用快速无损压缩，像素不变，文件可能稍大；JPG 保持原有质量设置。

分析按 CPU 和可用内存并行处理每张照片。第一轮全部完成后，再核验需要邻帧证据的局部遮挡，结果仍按原照片列表顺序生成。分析按钮下的进度条显示当前阶段（对齐照片、核验遮挡、生成预览）的完成数量和百分比；准备参考图、元数据、缓存或清晰预览时显示忙碌状态。导出按钮下另有进度条，按实际完成写入的图片计数；最终校验结束后才显示“导出完成”。

分析和导出期间主按钮提供取消。任务失败或取消会停止派发新照片，等待正在处理的任务结束，再删除本次新建的输出目录，已有文件不受影响；进度条显示取消或失败状态，不会保留忙碌动画。后台线程真实结束前不会允许重复启动，关闭窗口也会等待协作取消完成。

“分析并预览成片”失败且能定位到当前列表中的照片时，自动打开 A/B 原图对照：左侧 A 钉住列表第一张（不一定是参考图），右侧 B 选中失败照片，照片列表同步选中，保留已计算的逐区诊断。无共同画幅时定位到按列表顺序加入后首次使交集为空的照片。图片本身损坏时右侧显示读取失败，不沿用上一张的画面。取消、过期任务、工作区缓存恢复失败及导出失败不会触发此切换；无法归属单张照片的整组错误仍显示原因。

分析解码、参考区匹配或共同画幅失败时，先保留**列表中第一张失败照片之前连续成功的照片**，用这些照片重新计算共同画幅并生成成片预览。多线程的完成顺序不影响保留范围；不重新解码或匹配已有成功帧。进度条显示“已生成前 N/M 张成片预览”。失败后仍可在 A/B 检查问题，切回“成片预览”会选中首张成功帧，可以翻页、播放及升级清晰图。失败帧和之后的照片不进入该播放序列；第一张就失败或参考图无法读取时，没有可保留的前缀。

部分预览只保留在本次会话，“导出全部”仍需整组分析成功后使用。修改任一输入照片/XMP、列表顺序或参考参数会使它失效；修正失败原因后重新分析即可替换为完整结果。部分结果不会写入完整分析缓存，避免下次分析误命中而跳过失败照片。

## 对齐与最大裁切

- 在经过方向纠正的原图坐标中估计每帧相对参考照片的平移。
- 先用 NumPy 相位相关与局部 DFT 精确匹配小位移；同位置小块失败后，自动在有界缩略图上做整图零均值归一化相关搜索，再对候选位置局部细化。模板始终来自原参考图，切图不会逐帧更新模板或累计漂移。不增加 OpenCV 等运行时依赖。
- 搜索拒绝无纹理、低相似度和多个相似候选，不通过降低置信度阈值来强行补偿。失败信息包含对应选区的具体原因。
- 第一遍匹配后，对前后相邻帧均可靠的孤立失配做局部遮挡核验：邻帧只限定搜索窗口，必须在当前图找到至少两个一致的参考子块，其中一个高度相似。不直接使用插值坐标，不将恢复结果级联给其他连续失配帧。
- 多参考区按位移聚成一致组，不再要求占全部候选的严格多数。优先使用支持最多的可靠组；同等支持且方向冲突时，要求明显的相关质量差，否则拒绝随意选择。只剩一个可靠区域也可对齐。冲突、越界区域从补偿中排除，按共识位移预测它们的显示位置。
- 一致组还能限定其他区域的局部搜索窗，但每个恢复区域仍须通过完整纹理相关和边界检查，不能把预测框直接算作成功。
- 最终平移取整到原图像素，在参考坐标中求所有平移后画幅的交集。这就是平移模型下所有照片共同覆盖的最大矩形；每帧用同样宽高的源图像素框裁切，不缩放、不插值扭曲。默认不补空白；开启补边后求全部画面的并集，图外补黑，原图像素原样复制。参考选区并集是匹配证据范围，不是最终裁切框；一个可靠区域足够计算平移。
- 例：200×160 的两张图相差横向 +5、纵向 −3 像素，100% 补偿后默认统一输出 195×157；开启补边则为 205×163。
- 一个区域失配但其它区域仍可靠时，可由剩余区域确定平移。全部失配、多个冲突组无法可靠区分或未开启补边且无共同画面时，分析报出对应原因并停止，不把未对齐图冒充成片。
- 补偿强度默认 100%；降低强度只补偿部分位移，0% 不补偿，仍统一裁切尺寸。参考照片可以不在当前列表中，仍会验证其文件签名。
- 不同原图尺寸按原生像素坐标求交，不主动放大图像。这仍是平移模型，不修复旋转、变焦、透视或主体形变。选区应有稳定纹理、同一运动，避免混合运动的鸟和静止背景。

参考：[亚像素配准论文](https://doi.org/10.1364/OL.33.000156)、[OpenCV 相位相关说明](https://docs.opencv.org/4.13.0/d7/df3/group__imgproc__motion.html)。零均值归一化模板相关公式见 [OpenCV 模板匹配说明](https://docs.opencv.org/4.x/de/da9/tutorial_template_matching.html)，这里以 NumPy FFT 和积分图实现。算法不宣称对所有素材最优。

## 状态与实现

选区、强度和补边选项随工作区保存；完整分析结果可从本机缓存恢复，部分预览只保留在当前会话。修改选区、强度、补边选项、照片列表或源图/XMP 后需要重新分析。前面模板设置的变化不会让独立成片失效，也不会改变其输出。整组失败时保留连续成功前缀的成片预览及已计算的逐区诊断，可回原图或 A/B 检查；部分结果不能通过“导出全部”输出。取消后拒绝迟到结果；用户主动返回编辑视图时，后台完成不抢回成片视图。

- 默认交集模式分析后，“编辑构图”和 A 原图对照用青色虚线标出成片保留范围并遮暗外围，沿用工具栏“裁切效果”开关。分析信息显示当前原图面积保留比例；低于一半时提示可开启补边。标记和遮罩不写入导出。
- [sequence_geometry.py](../birdstamp/image_dejitter/sequence_geometry.py)：越界画幅的补边裁切几何、有界成片缩略图与原图坐标转换，焦点、鸟体和跟踪辅助层共用。
- [region_consensus.py](../birdstamp/image_dejitter/region_consensus.py)：可靠位移组选择、离群剔除、逐区拒绝原因与预测框。
- [editor_ab_preview.py](../birdstamp/gui/editor_ab_preview.py)：独立对照照片/模式/缩放，以及 A 图单 worker、最新请求合并、真实结束前保留所有权。原图复用缓存小图再后台升级；播放期间暂缓 A 图清晰解码。
- [editor_tracking_overlay.py](../birdstamp/gui/editor_tracking_overlay.py)：原图与最终裁切坐标之间的黄/红诊断层映射，显示信息不写入成片。
- [region_template_search.py](../birdstamp/image_dejitter/region_template_search.py)：有界整图粗搜、局部细化、歧义拒绝与孤立遮挡子块核验。
- [sequence_preview.py](../birdstamp/export_stage/sequence_preview.py)：输入签名、逐区跟踪、多区共识、整组公共矩形与各帧源像素框。
- [ImageProcSequenceAlignStage](../birdstamp/image_pipeline/image_proc_stage/image_proc_sequence_align_stage.py)：独立 `ImageProcStage`，通过 `ImageProcContext` 传递图像与实际裁切几何；预览和独立导出使用同一入口。普通模板管线保持独立。
- [sequence_export.py](../birdstamp/export_stage/sequence_export.py)：PNG/JPG 整组输出，使用 `PngExportStage` 终端描述；新目录隔离，异常/取消回滚。
- [editor_dejitter.py](../birdstamp/gui/editor_dejitter.py)：原生 Tab、选区列表、独立流程、同一预览画布与焦点/鸟体/参考线映射。
- [editor_sequence_preview_worker.py](../birdstamp/gui/editor_sequence_preview_worker.py)：分析、按需预览和整组导出的 Qt 工作线程与取消。
- [editor_sequence_transport.py](../birdstamp/gui/editor_sequence_transport.py)：播放面板、缩略图条、方向键物理/重复事件和精确定时器；切换 Tab、失去焦点、失效或关闭时停止，松键仅提交当前帧一次。普通导出页仍保持原生照片列表导航。
- 分析解码时同时保留有界原图小预览，按最终源像素框生成快速成片；切图先显示小图，停留 120ms 后再由单一后台 worker 生成清晰帧。连续播放/长按只使用整组小图缓存，不逐帧启动模板渲染、原图解码或鸟体识别。编辑构图也可复用原图小预览和已分析的跟踪框。
- `editor_options.json` 配置成片清晰预览长边（默认 1600）与缓存预算（64 MiB），快速预览长边上限（768）与整组原图/成片缓存预算（64 MiB），播放默认帧率（8），`dejitter_pad_to_union` 补边默认关闭。整组越大，快速预览分辨率自适应降低以限制内存；不会缩放或改变导出计划。导出始终重新读取原图，使用已确认的同一组像素框。

非 GUI 调用可直接使用 `prepare_sequence_preview`、`render_sequence_preview_frame` 和 `export_aligned_sequence`。`prepare_sequence_preview(..., allow_partial=True)` 可返回带 `failure` 的成功前缀，默认仍在整组失败时抛错；调用方应检查 `partial`，整组导出不接受部分结果。单图 `birdstamp render` CLI 仍走模板流程，不隐式改变旧参数契约；独立多参考区命令行参数尚未提供。

## 随工作区恢复分析结果

完成“分析并预览成片”后，跟踪结果、共同裁切几何和预览自动缓存到本机。保存工作区或退出后，下次恢复该工作区会直接加载已有分析与预览；已生成的清晰帧也会复用，尚未生成的帧在停留时按需补充。原图、XMP、照片列表/顺序、参考区、补偿强度或补边选项变化会使旧结果失效；普通模板修改不影响独立去抖动结果。

缓存缺失或损坏时可重新点击分析。磁盘缓存默认最多 512 MiB、8 组，会自动淘汰旧结果；仅拷贝 workspace 文件到另一台电脑不包含本机缓存。清除/删除选区在去抖动面板或参考图右键中操作，预览工具栏不再放重复的“清除参考区”按钮。
