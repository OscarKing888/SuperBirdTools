# A/B 预览工具栏与对齐约定

## 控件归属

| 层级 | 控件 | 作用与布局 |
| --- | --- | --- |
| 顶部编辑工具 | 选择、参考区、裁切 | 参考区工具在去抖动页作用于 A/B 各自的原图：参考图编辑定义，目标图修正对应编号的匹配；成片不可编辑。普通模板构图使用单视口编辑预览。 |
| 顶部公共显示 | A/B 开关、同步缩放/移动、裁切遮罩及 Alpha、焦点框、鸟体框、构图线及线宽 | 显示选项供两侧共用；联动只在 A/B 开启时可见。顶部去抖动页签和底部播放条占整个预览宽度，显隐同时改变两边可用高度。 |
| 每侧工具行 | A/B 标识、当前文件名、播放/暂停、原图、去抖动成片、显示 RAW、自动焦点居中、适应窗口、缩放比例 | 激活侧显示蓝色“当前”标识，画布外围显示蓝色边框；点击播放按钮会激活该侧并播放当前模式的照片序列，另一侧保持原照片。文件名过长时中间省略，悬停显示完整路径。模式为互斥工具按钮，两侧可独立选择。适应窗口不重新解码或渲染。不再提供文件下拉框或钉住功能。 |
| 视口底部 | 原始尺寸、成片尺寸、缩放及模式状态 | 始终单行等高；长提示不会挤宽分栏，悬停可读完整内容。 |

## 各模式的显示与隐藏

| 状态 | A | B | 显隐规则 |
| --- | --- | --- | --- |
| 单视口 | 整个面板隐藏 | 当前编辑照片 | B 工具行保留但不显示 B 标识，普通导出页隐藏独立模式按钮；不显示激活边框。 |
| 普通编辑 + A/B | 可选择原图或已分析成片 | 可选择原图或已分析成片 | 两侧工具行均显示；关闭 A/B 恢复普通编辑预览。 |
| 去抖动编辑 + A/B | 独立原图/成片 | 原图 | B 模式可切换原图/成片，与顶部“编辑构图 / 成片预览”页签同步。 |
| 去抖动成片 + A/B | 独立原图/成片 | 去抖动成片 | 保留全部行。两侧都是成片时禁用公共裁切遮罩及 Alpha；存在原图视口时可再次使用。 |
| 未选照片、等待分析或加载失败 | 占位画布 | 占位画布 | 保留全部行，只禁用依赖已有图像的适应和缩放；允许预设焦点居中。 |
| 播放开始/停止、底部缩略条显隐 | 本侧按钮播放原图或已分析成片 | 本侧按钮播放原图或已分析成片 | 播放和列表导航只更新激活侧，另一侧保持照片；共用帧率、循环和缩略条位于分栏外，普通原图无分析结果也可播放。 |

点击画布或工具栏（含文件名及键盘焦点进入）激活该侧；随后照片列表的新选择只加载这一侧。激活时同步列表高亮而不重新加载另一侧，蓝色边框随激活侧移动。初次开启默认激活 B，A 默认参考图；分析失败时自动设 A 为列表第一张、B 为失败图，并激活 B。A 保持独立后台预览，B 保留普通编辑上下文。

“同步缩放/移动”默认关闭，默认值来自 `editor_options.json` 的 `preview_ab_linked`。开启瞬间锁定两侧当前的缩放比例和归一化中心差；之后在任一侧缩放、拖动或点适应窗口时，只同步本次倍率变化和中心位移，另一侧保留原有的相对缩放与位置。清晰帧到达或分栏尺寸变化恢复各侧自己的视野，不重新分析或修改裁切。图片边界仍限制可平移范围，抵达边界时实际中心差可能缩小。联动会关闭两侧自动焦点居中；重新启用任一侧焦点居中则退出联动，避免两种定位互相覆盖。

不按单侧的状态隐藏整条工具栏，也不依赖空格或某个固定像素高度凑齐。两个视口使用同一组件与相同布局层级，并在字体、样式或布局度量变化后统一行高。分隔条可以改变两边宽度，但画布上沿、下沿以及状态栏始终对齐。

“显示 RAW”只在本侧源文件为 RAW 且处于原图视图时出现。A/B 各自记住本次窗口会话的开关状态；开启后后台解码完整 RAW 并缩至预览尺寸，播放期间仍使用快速小图，停止后升级。该开关不会改变成片和任何导出帧的来源。
