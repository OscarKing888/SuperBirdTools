# A/B 预览工具栏与对齐约定

## 控件归属

| 层级 | 控件 | 作用与布局 |
| --- | --- | --- |
| 顶部编辑工具 | 选择、参考区、裁切 | 参考区工具在去抖动页作用于 A/B 各自的原图：参考图编辑定义，目标图修正对应编号的匹配；成片不可编辑。选择/裁切工具仍操作当前编辑照片（双栏时为 B），保留切回编辑视图的行为。 |
| 顶部公共显示 | A/B 开关、裁切遮罩及 Alpha、焦点框、鸟体框、构图线及线宽 | 显示选项供两侧共用。顶部去抖动页签和底部播放条占整个预览宽度，显隐同时改变两边可用高度。 |
| 每侧第一行 | A/B 标识、照片选择、跟随关系、图像模式 | A 使用“钉住”，B 显示“随列表”；对应列同宽。A 原图/去抖动成片独立于 B。 |
| 每侧第二行 | 自动焦点居中、适应窗口、缩放比例 | 顺序、间距及行高一致，各自只控制所属视口。适应窗口不改变焦点居中开关，也不重新解码或渲染。 |
| 视口底部 | 原始尺寸、成片尺寸、缩放及模式状态 | 始终单行等高；长提示不会挤宽分栏，悬停可读完整内容。 |

## 各模式的显示与隐藏

| 状态 | A | B | 显隐规则 |
| --- | --- | --- | --- |
| 单视口 | 整个面板隐藏 | 当前编辑照片 | B 照片/模式行收起；视口操作行仍保留。 |
| 普通编辑 + A/B | 可选择原图或已分析成片 | 编辑预览 | 两侧照片/模式行和操作行均显示。B 模式显示“编辑预览”并禁用切换，不隐藏。 |
| 去抖动编辑 + A/B | 独立原图/成片 | 原图 | B 模式可切换原图/成片，与顶部“编辑构图 / 成片预览”页签同步。 |
| 去抖动成片 + A/B | 独立原图/成片 | 去抖动成片 | 保留全部行。两侧都是成片时禁用公共裁切遮罩及 Alpha；存在原图视口时可再次使用。 |
| 未选照片、等待分析或加载失败 | 占位画布 | 占位画布 | 保留全部行，只禁用依赖已有图像的适应和缩放；允许预设焦点居中。 |
| 播放开始/停止、底部缩略条显隐 | 独立或跟随 B | 当前播放帧 | 播放条位于分栏外，不在某一侧追加一行。 |

不按单侧的状态隐藏整条工具栏，也不依赖空格或某个固定像素高度凑齐。两个视口使用同一组件与相同布局层级，并在字体、样式或布局度量变化后统一行高。分隔条可以改变两边宽度，但画布上沿、下沿以及状态栏始终对齐；不同图像比例和独立缩放不会被强行统一。
