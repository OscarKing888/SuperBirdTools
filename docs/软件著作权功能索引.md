# SuperBirdTools 软件著作权功能索引

## 1. 文档用途

本文是为后续撰写软件著作权材料（功能说明书、用户手册式的模块划分、源代码鉴别材料的文件抽取）准备的功能索引底稿，不是提交稿本身。

文中的产品名称、版本规则和功能描述来自仓库内的产品配置、使用说明、架构文档和实现代码。每条功能标注主要代码位置，便于按模块抽取源代码。本文不摘录长段源代码，也不记载开发约束、测试命令或持续集成细节。

软件套件在源码与安装包中的工程名是 SuperBirdTools。面向用户的两个主应用分别叫「极速鸟瞰」和「极速鸟框」。

### 版本号如何组成

源码里的 `app_metadata.json` 只保存主版本和次版本，格式为 `MAJOR.MINOR`（当前为 `1.0`）。完整显示版本由程序在此基础上追加当前源代码提交哈希的前 8 位十六进制字符，形如 `1.0.a1b2c3d4`（示例中的第三段表示 8 位哈希，不是固定字面量）。

- 源码直接运行时，`app_identity.py` 的 `load_app_identity()` 读取前两段，再经 `git_version()` 取 Git HEAD 的前 8 位，拼成 `主版本.次版本.哈希`。
- 打包后的程序不再依赖本机 Git。构建时把同一规则生成的完整版本写入包内配置，窗口标题、关于对话框和安装包名称使用这份完整版本。
- macOS 应用包的数字短版本使用 `主版本.次版本.0`；Windows 可执行文件的数字版本资源使用 `主版本.次版本.0.0`。界面上仍显示带哈希的完整版本，因为系统数字版本字段不能包含字母。
- `build_number` 是 macOS 构建号，与界面上的三段显示版本不是同一字段。
- 窗口标题里的 `{app_name}` 由产品名和副标题用「 - 」连接而成（`AppIdentity.app_name`）。

### 开发目的

本套件是「慧眼选鸟」（SuperPicky）的配套软件，用于鸟类照片的浏览筛选和后期出图（`使用说明.txt`、两款应用的副标题）。

- 极速鸟瞰：打开慧眼选鸟处理过的目录，查看和修改鸟种等信息；可再次识鸟、按只识别、重算连拍；并可做清晰度判断和 RGB 降噪。使用说明将清晰度计算和内置降噪标为实验性功能。
- 极速鸟框：对鸟类照片批量裁切，把拍摄信息排成文字，叠加签名等贴图，并对连拍做去抖动，导出静态图、GIF 或视频。

### 运行环境与发行形态

两款主应用是桌面图形程序，面向 macOS 与 Windows。

- macOS 发行形态为三个原生应用包：`SuperViewer.app`（极速鸟瞰）、`SuperBirdStamp.app`（极速鸟框）、`SuperBirdUpdater.app`。当前自动构建的 macOS 产物为 arm64。
- Windows 发行形态为同一安装目录下的 `SuperViewer/`、`SuperBirdStamp/`、`SuperBirdUpdater/`。合并发行包中的两个主应用目录互相引用运行库，需要放在同一个压缩包里一起分发，不能单独拿走其中一个目录。
- 首次安装使用完整套件压缩包，名称形如 `SuperBirdTools-<主版本>.<次版本>.<8位哈希>-<平台>-<架构>.zip`。两个主应用与更新器放在同一可写目录。安装后可从菜单检查更新；百度网盘链接保留为手动获取安装包的入口（`使用说明.txt`、关于对话框、`SuperBirdUpdater/README.md`）。
- 从源码运行时需要 Python 3.10 及以上，并安装各应用依赖。打包后的 `.app` / Windows 程序目录面向最终用户，不要求用户自行安装 Python。

## 3. 总体功能概述

极速鸟瞰解决「从一大批鸟片里快速看、筛、改信息」。用户选择照片目录后，以列表或缩略图浏览，预览原图、RAW 或已有降噪成片，查看相机参数、鸟名、评级和标签，并把修改写入照片旁边的 XMP 侧车，不改原图，也不改慧眼选鸟的 `report.db`。在此基础上可以重算连拍、调用本机识鸟服务、测量鸟是否清晰、批量降噪，以及把选定鸟种归档到按鸟名组织的目录。

极速鸟框解决「把一组鸟片做成可发布的画面」。用户导入照片或目录，设定裁切、文字模板和贴图，预览后再导出 PNG/JPEG、GIF 或视频。连拍可以按参考区域对齐（去抖动）后导出稳定序列。处理参数和照片列表可以保存为工作区，下次继续编辑。

两款应用共享这些用户可感知的能力：同一套照片格式；同名 `.xmp` 侧车；只读兼容慧眼选鸟 `report.db`；按文件就近使用 `.superpicky` 缩略图缓存；预览构图线、对焦点和焦点居中；鸟名拼音、稀有度与保护等级徽章；拍摄地点字段；把文件发给对方应用；跟随系统深色/浅色主题。极速鸟瞰负责写入和筛选这些信息，极速鸟框负责把已有信息排进模板并出图。降噪成片由极速鸟瞰生成，极速鸟框只在预览里查看已经生成的成片。

## 5. 分模块功能说明

### 极速鸟瞰

#### SV-01 启动、主窗口与关于

用户从应用包、Windows 程序或 `python -m SuperViewer` 启动极速鸟瞰。程序加载产品身份，建立主窗口，恢复上次打开的目录。若程序已在运行，再次打开文件会交给已有窗口。macOS 还接受系统的「打开文件」事件。

- 输入：启动参数或系统转入的文件路径；用户配置目录中的上次目录。
- 输出：主窗口。标题含产品名、副标题、完整版本和作者。
- 菜单：文件（珍禽入册、发送到外部应用、外部应用设置）、编辑（标签撤销/重做）、设置（用户选项、性能探针日志）、帮助（关于）。更新菜单在安装包中由更新器接入。
- 关系：主窗口把目录、列表、预览和右侧信息页接在一起（`MainWindow`）。性能探针只往日志写耗时，不改变照片。

#### SV-02 目录浏览与文件列表

用户在左侧目录树选择文件夹。标题栏「包含子目录」默认开启，选择会记住。列表显示文件名以及光圈、快门、ISO、焦距、镜头、机身、拍摄时间、连拍、清晰度、美学分数、对焦状态、鸟名和稀有度等列。

- 输入：所选目录；若目录树中存在慧眼选鸟 `report.db`，则作为只读补充。
- 输出：当前范围内的照片列表；Viewer 同时列入视频。关闭「包含子目录」后只保留当前这一层。
- 关系：列表选中后驱动预览（SV-04）和信息页（SV-09）。目录右键可复制完整路径，并挂接清晰度、连拍、识鸟、降噪等动作。文件右键菜单由 `file_context_menu.build_file_context_menu()` 分组为复制/粘贴、鸟名、珍禽入册、星级、标签、鸟种信息、拍摄信息、分析与处理、发送到、定位文件和删除。

#### SV-03 缩略图、排序与筛选

缩略图与列表是同一批过滤后的文件。缩略图档位为 128、256、512、1024、2048。卡片下方显示鸟名、稀有度/保护等级徽章、筛片状态，文件名和连拍编号在底部。悬停可看被省略的全名。

- 用户可按列表已有字段升序或降序排列，表头与缩略图排序栏双向同步。默认按文件名排序，不因慧眼选鸟把照片分到不同子目录而打乱相机文件名顺序。
- 筛选可组合文字、星级、精选、排除、对焦和标签。文字按空格分成多个词，每个词可以命中文件名、备注或标签，需同时满足。
- 任一筛选开启时，连拍分组色带隐藏，避免滤掉中间张后色带失真。
- 可见区域优先生成缩略图，并在后台继续写入持久缓存。列表模式不生成缩略图。

#### SV-04 照片预览与来源切换

选中一张照片后，预览区按类型决定怎么显示：

- 较小的 JPEG 等非 RAW 直接显示完整预览（默认同步上限约 40 百万像素）。
- 更大的图先显示当前缩略图档位，再在后台换成完整图。
- HEIF/HIF/HEIC 使用更低的同步上限（默认约 4 百万像素）；超过后若没有现成小图，则显示「正在加载预览」，由后台解码，避免界面卡住。
- RAW 在界面线程只显示已有缩略图或「正在加载预览」。完整预览默认使用长边至少 1600 像素的相机内嵌 JPEG，没有或太小时再解码完整 RAW。

每个视口可以在「默认预览 → 显示 RAW → 显示降噪」之间循环，也可以从菜单直接选择。非 RAW 不能选「显示 RAW」；视频隐藏该按钮。选择只在本次窗口有效，不写入配置，也不改缩略图缓存。降噪模式只查找已经导出的成片，找不到就回到原图并说明原因。

进入一个目录后，第一张有效照片会适应窗口。用户若在等待清晰图时自己缩放或拖动，则以手动视野为准。

#### SV-05 A/B 对照与构图线

「A/B 对照」默认关闭。打开后左右各有一块预览，新的列表选择只更新当前激活的一侧。两侧都可以看原图或原视频，没有极速鸟框那种「原图/成片」切换。可选「同步缩放/移动」。打开对照时文件列表会暂时变窄，关闭后恢复。

构图线画在预览上，可选：不显示、均分九宫格、黄金分割九宫格、方格网格、对角线加方格、中心十字线。线宽为 1–32 像素。A、B 两侧的构图线和对焦点开关互相独立，主工具栏只保留对照和视野同步。这些线用于观看；Viewer 没有单独的「导出带构图线的成片」菜单。画布提供把当前叠加画到源尺寸图像上的函数，供预览和校验使用（`PreviewCanvas.render_source_pixmap_with_overlays()`）。

#### SV-06 按住方向键快速浏览

第一次按下方向键按普通方式选中并加载。系统开始自动重复后，程序改用自己的计时器，按用户设定的速度换图，只显示当前档位的缩略图，不读取完整图、不刷新 EXIF、不提取焦点。只有真正松开按键才对最后一张做完整加载。点击预览画面后，方向键仍交给文件列表。`[` 记下区间起点，`]` 选中从起点到当前图的一段，不重新加载预览。

快切过程中若已打开「显示对焦点」或「显示鸟体」，只使用已经在内存里的框，不为每一帧重新分析。

#### SV-07 对焦点显示与自动居中

打开「显示对焦点」后，预览上画出相机记录的对焦区域。程序按 RAW、HEIF 和普通图片分别读取焦点；文件里没有时，才使用报告库中的焦点坐标。RAW 完整解码时，焦点会按相机 JPEG 在传感器上的裁切范围换算，避免框画到画面外。

「自动焦点居中」默认关闭，开启后会记住。焦点中心锁定在预览中央；没有焦点时用图像中心。它只改变观看位置，不裁照片。与「显示对焦点」可以分别开关。

#### SV-08 显示鸟体

「显示鸟体」默认关闭，对 A/B 两侧都有效。停留在一张照片上后，程序用本地鸟类检测模型找出鸟框：多只鸟都画出来，综合置信度和面积最高的主体加粗。很小的鸟会再用更高分辨率补检；第一遍完全没找到鸟时，会做与清晰度相同的补找（暗部提亮、更大输入、焦点附近放大），仍只画框、不测清晰度。

结果缓存在侧车的鸟体缓存字段里，同一 XMP 上的 RAW 和 JPEG 分开保存。按住方向键时只读内存，不启动检测。缺模型时在状态栏说明，不能检测。

#### SV-09 图片信息与 EXIF

右侧有三个页：「图片信息」「标签管理」「EXIF」。只有当前页会刷新，避免切换照片时读无关内容。

- 图片信息展示与列表一致的拍摄和报告字段，尺寸来自真实图像而不是缩略图。可编辑标题、备注、评级、精选等，回车或离开输入框后写入同名 XMP。
- EXIF 页列出 ExifTool 读到的标签，含相机厂家私有信息。有对焦距离时排在优先区域。此页以查看为主；从表里改可写字段时同样进 XMP，不改原图。
- 正在输入的备注和文件名不会被后台读到的旧数据覆盖。

#### SV-10 标签

标签词表来自照片库 `.superpicky/tags.cfg`，没有则用应用自带的 `SuperViewer/tags.cfg`。缩进表示分组，只有最末级词语会写到照片上。

- 用户可在菜单或标签页勾选标签，支持多选照片。
- 「编辑标签…」用树形草稿增删改名和移动；保存时把变更同步到当前目录及子目录的照片侧车。配置和照片作为一次操作，失败可以恢复。
- 编辑菜单和工具栏提供标签撤销/重做，最多 100 步，不写入磁盘。在文字框里打字时，撤销快捷键还给文字本身。
- 更换标签库、改名或直接改主题词会清空这段历史。

#### SV-11 识鸟与鸟名

在已安装并能提供本地 HTTP 服务的慧眼选鸟上，用户可对一张、多张或整个目录识鸟。

- 置信度足够的结果写入中文名、英文名和置信度，并同步标准标题。置信度不足的候选记为待确定，不覆盖已确认鸟名。
- 结果窗口按候选列出，可采纳某一候选。也可不重新识别，只从已保存候选里选。
- 「逐只识别」先检出每只鸟，再分别送给识鸟服务，把每只鸟的名字和区域记在侧车。图片信息底部列出这些鸟；鼠标悬停鸟名时，预览框住该鸟并居中。用户可指定其中一只为主鸟。
- 「手动指定」从鸟种目录搜索并写入学名、拼音、简介等，同时保留用户备注和标签。
- 复制鸟名 / 粘贴鸟名（macOS ⌘⇧C / ⌘⇧V，Windows Ctrl+Shift+C / V）把中英文名、拼音、稀有度、保护等级和拍摄地点一次性贴到所选照片，不复制相机参数和评分。

没有识鸟服务时，上述网络识别不可用；拼音词表和已写在侧车里的鸟名仍可使用。

#### SV-12 拼音、稀有度与保护等级

拼音来自内置带声调鸟名词表，不需要联网。信息页在已有鸟名但没有拼音时提供「更新拼音」；目录右键可对当前目录或含子目录批量补写。已有拼音不会被覆盖。

稀有度按 0–100 分显示彩色徽章，保护等级按 IUCN 类别显示另一枚徽章。列表有稀有度列，缩略图上也显示。用户可在右键菜单把分数改为固定档或自填两位小数，名称和颜色可在用户选项里改（例如把档位文案改成更短的词）。这些值写入 XMP。

#### SV-13 拍摄地点与拍摄时间

「拍摄地点」是独立文字，可在信息页或右键菜单编写、复制、粘贴到多张照片。它不从 GPS 推算，也不占用清晰度使用的城市类字段。留空表示清除。

「从同名 RAW 更新拍摄时间…」只处理所选 PNG/JPG/JPEG：在用户指定的 RAW 目录（含子目录）里找同名 RAW，把原始拍摄时间写入 JPEG/PNG 的侧车。找不到或有多个同名时逐张报告。RAW、原图和 `report.db` 都不修改。

#### SV-14 连拍信息

目录右键「计算连拍信息」让用户设置相邻两张的最大时间间隔和每组最少张数。程序按亚秒拍摄时间把同一目录的照片分组，写入连拍组号和组内序号。同一目录、同一主文件名的 RAW+JPEG 算一张。不属于任何连拍、但报告库里仍有旧组号的，写成 0，界面显示为空。

列表用「连拍」列，格式为 `(组内序号/组号)`。缩略图把该编号放在底部文件名上，不在照片上盖大字。同一组至少两张可见时，列表和缩略图用半透明色带把这一组连在一起，相邻组换色。

#### SV-15 鸟清晰度

本功能回答的是：对焦成功不等于鸟清楚。程序在较高分辨率上找鸟，测量鸟身体（优先头部）边缘有多「糊」，给出清晰 / 可用 / 失焦或运动模糊，并换成与慧眼选鸟相同的 0–1000 锐度分数，写入侧车里既有的锐度位置，同时写入本软件自己的清晰度明细字段。列表「鸟清晰」列、缩略图底栏和信息页会更新。

对用户可见的分支是：

- 找到鸟：以最清晰的一只代表整张照片；每只鸟的结果可在计算过程里查看。
- 没找到鸟但有对焦点：测量焦点附近。
- 没找到鸟且相机是手动对焦：测量画面中部较清晰的一块，当作焦平面。
- 否则：测量整幅画面（相机画幅内）。

用户在「设置 → 用户选项 → 鸟清晰度」里选择检测模型、是否用分割模型修轮廓、测哪些像素、是否忽略太小的鸟、无鸟时怎么分块等。右键「查看清晰度计算过程…」逐步显示解码、找鸟、测边缘和结论，默认不写回侧车。图像来源可在 RAW、相机 JPEG 和降噪成片之间对比；用户选项里的默认来源是相机内嵌 JPEG，与「按 RAW 标定阈值」不是同一件事。非默认参数会记在算法版本后缀里，避免和旧结果混用。

计算过程窗口里还有研究用的模型链：把检测模型和分割模型串起来看中间结果，并对这些框再测一次清晰度。该测量使用临时图，不写 XMP。完整权重不一定随安装包提供：发布包侧重检测用的较小模型；轮廓和鸟眼模型可来自已安装的慧眼选鸟，或由用户在设置中下载。缺少鸟眼模型时按整只鸟测量，进度窗口会提示准确度下降。

使用说明把清晰度计算标为实验性功能。算法版本与逐步分支见 `docs/bird_sharpness.md`、`docs/bird_sharpness_flowchart.md`，本文不重复阈值表。

#### SV-16 批量降噪

用户对一张、多张或整个目录运行 RGB 降噪。RAW 会先显影成普通彩色图再降噪，不输出 DNG，也不改源照片和原侧车。成片默认写到照片目录下的 `denoised` 子目录，文件名带 `_denoised`，并带一份新的 XMP。也可指定固定目录或每次选择目录。输出可选 16 位 TIFF 或 JPEG。强度 0–100% 表示原图与降噪结果的混合，0% 只做显影或格式转换。

进度窗口可停止，并可打开已完成文件所在目录。预览工具栏的「显示降噪」只打开已经生成且能对上源照片的成片。使用说明把内置降噪标为实验性功能。模型随极速鸟瞰发行，运行时不下载。

#### SV-17 珍禽入册

「珍禽入册」按鸟名把所选照片移动或复制到归档目录。文件名可加拍摄时间前缀。鸟名目录下按格式再分子目录：RAW/HEIF 进 `RAW`，PSD 进 `PSD`，PNG/JPEG 进 `Export`。同名冲突时整组加序号。侧车随照片一起走；选中 RAW 时，同目录的 `.acr` 文件一并带入 RAW 子目录，程序不改写 ACR 内容。没有鸟名的照片跳过。

方式、目标目录和是否加日期在「用户选项 → 珍禽入册」里配置。文件菜单和右键菜单都能开始。成功后当前目录列表会刷新。

#### SV-18 视频浏览与播放

浏览器可以收录常见视频（如 mp4、mov、mkv、avi 等，见 `app_common/video.py` 的扩展名列表）。缩略图显示播放标记和时长；列表增加时长、分辨率、帧率和编码列。

选中视频后，右侧改为视频信息而不是照片 EXIF。先显示封面，只有用户按播放才打开播放器。控件包括播放/暂停、重播、0.25–2 倍速、音量和静音。进度条上可显示整段音量波形；其上方有一条均匀抽样的序列帧，两者都能点击定位。快切到视频时只显示已有封面，不开始播放。视频不使用照片的构图线和焦点工具。

#### SV-19 文件整理与发送

在列表或缩略图中可以复制、剪切、粘贴、重命名和删除。删除进入系统垃圾桶。同名 XMP 与照片一起复制、移动、重命名或删除。剪切或移动失败时，程序保留仍完整的那一份并报告路径。删除当前图后，选择移到过滤结果中的前一张。

「发送到」把选中文件交给用户配置的外部程序，或发给极速鸟框。可在文件菜单维护外部程序列表。「在访达/资源管理器中显示」和「复制文件全路径」用于定位。「浏览预览图像」「浏览原图像」在系统文件管理器中打开已有缓存或源文件。

#### SV-20 用户选项、主题与更新

用户选项集中在一个带左侧分页的对话框里，包括浏览与性能、批量降噪、珍禽入册、稀有度徽章、保护等级徽章和鸟清晰度。确定后才写入用户目录的 `SuperViewerUser.cfg`；取消不保存。

界面颜色跟随系统深色或浅色，不因此重新读照片。星级、标签筛选和预览开关在选中时使用蓝底白字。

安装包中的「更新 → 检查更新」由 SuperBirdUpdater 提供。源码直接运行默认不替换程序文件。

### 极速鸟框

#### BS-01 启动、导入与关于

用户启动极速鸟框后进入编辑器主窗口。可以从文件菜单加入照片或目录，拖入文件，或接收极速鸟瞰等程序发来的路径。拖入 `report.db` 时，程序把它登记为只读报告来源。若收到的文件附近若干层有 `.superpicky/report.db`，也会一并发现。

- 菜单：文件（添加文件、添加目录、新建/打开/保存工作区、最近工作区）、设置（用户选项、性能探针日志）。导出动作在左侧导出栏，快捷键为导出当前（Ctrl+E）和批量导出（Ctrl+Shift+E）。
- 关于对话框使用与极速鸟瞰相同的产品身份机制，作者与链接来自 `SuperBirdStamp/about.cfg`。
- 空工作区时会显示一张内置示例图，便于看到裁切和模板；一旦开始导入真实照片，示例不再盖住用户内容。

#### BS-02 照片列表与顺序

照片列表是本次编辑的队列，不是整盘目录浏览器。用户可以多选、从列表移除（不删除磁盘上的原图和 XMP）、调整起始编号，以及用上移/下移改变顺序。显示编号随起始编号和当前顺序变化，模板里的序号字段使用这个编号。

普通编辑时，方向键按当前列表顺序换图。长按时先显示较小预览，松开后升级最后一帧。这与极速鸟瞰的快速浏览类似，但节拍属于编辑器的播放条，而不是浏览器用的那一套连播开关。

新导入的照片接在列表末尾。元数据在后台读取，供列表、模板预览和导出共用。

#### BS-03 工作区

工作区是一个 JSON 文件，记住照片顺序、逐张裁切和叠加覆盖、报告库路径、当前选中项、全局处理设置、导出选项和预览状态。

- 启动时先尝试自动保存，再尝试上次工作区，分批把照片加回界面。恢复完成前不会用半截列表覆盖原文件。
- 中途关闭保留上一次完整的自动保存。
- 「新建工作区」清空当前列表和序列结果，回到原图编辑，不覆盖先前那个已命名工作区。
- 最近打开的工作区记在用户配置里，只有成功打开或手动保存的才进入列表。
- 用户数据目录：macOS 为 `~/Library/Application Support/BirdStamp/Config`，Windows 为 `%APPDATA%/BirdStamp/Config`。模板在同级 `templates`。自动保存文件名为 `editor_autosave.birdstamp-workspace.json`。

#### BS-04 预览、A/B 与构图

主预览显示正在编辑的照片。工具栏可在原图与成片（套用当前裁切和模板之后的效果）之间切换。A/B 打开后，点击一侧即激活该侧；列表选择发给激活侧。两侧都可以独立看原图或成片，并可同步视野。

与极速鸟瞰相同，每侧可在默认预览、显示 RAW、显示降噪之间切换，且只影响观看，不改变导出所用的源图规则。降噪同样只查找极速鸟瞰已经生成的成片。

每侧视口自己开关裁切遮罩、对焦点、鸟体框和构图线（种类与线宽同 SV-05）。构图线在极速鸟框里画在当前裁切框内部，而不是铺满整张原图。自动焦点居中只改变视野，不改变裁切结果。播放条提供帧率、循环和一条缩略图，原图与成片共用。

#### BS-05 裁切

裁切是出图的第一步。用户可以：

- 选择比例，包括原比例、自由比例和不裁切。不裁切时保留整幅，仍可只叠加文字。
- 用手动画框、平移；留边从中心向外扩展。
- 用对焦点或鸟体作为裁切中心。鸟体中心来自后台检测（`BirdDetectWorker`），检测完成前不覆盖用户已经手动画好的框。
- 为单张照片保存不同于模板的裁切。坐标按原图归一化保存，允许略超出画面以便补边。

拖动裁切手柄时，画面上会提示接近的短边分辨率档（默认 480、720、1080、1440、2160，可在编辑选项里改档位）。靠近时吸附，平移整框不吸附。吸附提示不写进导出的像素。

#### BS-06 模板与字段

模板是 JSON，描述文字、条幅和贴图如何排列。内置模板在首次需要时复制到用户模板目录，已有用户模板不会被覆盖。模板管理器可新建、复制、定位到文件，并立刻预览。预览比例可以跟随模板，或临时改成横版、竖版和常用画幅，试览不改模板文件。

字段取值顺序固定为：已合并的 XMP/EXIF，然后文件内信息，然后只读 `report.db`，最后编辑器自己的序号、裁切等。因此侧车里的鸟名、地点、评级会压过报告库里的旧值。鸟种拼音若没有显式字段，则用中文鸟名查内置词表。空的连拍号在模板里按缺失处理，不把「0」印成一组连拍。

「文本缩放」在自动字号上再乘 25%–300%。模板管理器右键可新增、复制模板，并在系统文件管理器中显示 JSON。

#### BS-07 叠加层

叠加层是模板上的有序对象：文字、徽章、图像（签名、贴图）和背景。旧模板若只有条幅和字段，读取时仍按原样绘制，直到用户开始按新图层编辑。

- 可在模板上改，也可只改当前照片。单张一旦改动，就保存一整份图层快照，之后换模板默认值不会悄悄改掉这张。
- 文字支持描边和阴影。徽章可自动按稀有度或保护等级上色，颜色定义与极速鸟瞰的用户选项一致。
- 图像可着色。对象可以组成行或列，自动对齐。
- 主窗口用停靠面板编辑叠加，支持撤销。拖动时不重新读元数据。
- 导出与预览使用同一套合成。图片、GIF、视频和命令行 `render` 都走这条路径。

#### BS-08 平台安全框

「安全框组」是每张照片的选项，默认关闭。开启后，按所选平台的横屏或竖屏边距，把叠加内容往内收，不改变照片裁切本身。内置组来自编辑选项，用户可在「设置 → 用户选项 → 安全区」里增删组、改四边百分比，并为横竖屏各指定一张参考图（只用于设置页对照）。

视频导出另有「显示安全框」：当用户指定了目标宽高比时，在裁切范围内用橙色虚线标出最终画面。这条线只帮助构图，不画进视频帧。实际视频仍按目标尺寸等比缩放并补边。

#### BS-09 图像处理管线

预览成片和导出共用同一条默认阶段顺序：

1. 模板裁切（`ImageProcTemplateCropStage`）
2. 限制长边（`ImageProcResizeLimitStage`）
3. 模板叠加（`ImageProcTemplateOverlayStage`）
4. 焦点叠加（`ImageProcFocusOverlayStage`）

裁切固定在最前，其余阶段的顺序可调整。每种可选阶段有自己的开关。改变开关或参数后，已缓存的导出帧作废。最终导出类型在管线末端单选：图片、GIF 或视频，三者互斥。

界面上，左侧「处理设置」按这个顺序展示阶段；「导出设置」在底部展开当前导出类型的参数。去抖动使用另一条对齐管线，不把参考区裁切悄悄混进普通模板导出。

#### BS-10 图片导出

「导出当前」处理正在编辑的照片，「批量导出」处理列表。输出为 PNG 或 JPEG。程序在写出前分配文件名，避免不同目录里仅大小写或 Unicode 形式不同的名字撞车，冲突时追加 `_2`、`_3`。

成片尽量从原文件复制拍摄信息（含相机厂家注记），再按成片的方向和尺寸校正，并重建缩略图。不能覆盖原图。没有 EXIF 的源文件仍可导出。独立的去抖动导出还会把原 `.xmp` 拷到成片旁边。

#### BS-11 GIF 导出

把当前列表按顺序合成 GIF。用户设置帧率（界面允许 1–240）。不超过 100 帧/秒时保留每一张，按 10 毫秒的粒度分配每帧时长，使总时长接近所请求的时长。高于 100 帧/秒时，按总时长抽样，不再保证一张照片对应一帧。

「重复播放」可在第一遍之后用更低或不同的帧率再播若干遍。可同时生成缩小版本；「微信表情」额外输出一个长边不超过 480 像素、体积受上限约束的 `__wechat.gif`。主 GIF 与各缩小版共用同一时间安排。进度显示实际帧数、帧率和时长。

#### BS-12 视频导出

视频面板设置尺寸、方向、自定义宽高、帧率、背景和编码器。帧先按 BS-09 渲染，再归一化到偶数尺寸，最后交给 FFmpeg 编码。只改帧率或编码器时，可以复用已经渲染好的帧。

「重复播放」与 GIF 类似：各遍帧率不同，但成片用一个恒定输出帧率编码，较慢的遍靠重复帧拉长。取消时保留已完成的帧，并尽量给出可恢复的部分视频或帧目录。关闭窗口时若视频仍在导出，程序要求先停止。

无压缩 AVI 作为一种编码选项提供。导出进行中，更新器不会强制退出本程序。

#### BS-13 连拍去抖动与主体稳定

「去抖动」页面向一组连拍，而不是单张模板。用户在原图上画一个或多个参考区域（也可用角点强度建议若干区域），程序跟踪这些区域在后续帧中的位置，求出大家共同覆盖的画面，从而减轻手持抖动。

- 编辑视图看原图和参考框；成片视图看对齐后的结果。
- 默认输出共同区域；也可以向外补边，保留并集范围。侧栏用示意图对比「共同区域」和「完整外框」。
- 分析失败时可以打开 A/B，一边看序列起点，一边看失败的那一张，并保留诊断框。
- 某一帧跟踪丢失时，可以手动改正该帧的对应位置，或添加接力参考图，从中间某一张继续往后跟。
- 对齐可以只平移，也可以在有足够参考区时估计轻微转动。
- 导出为对齐后的 PNG/JPEG 序列，写到新的子目录。可选择在导出成功后另建一个以成片为源的工作区。
- 「主体稳定」在背景对齐之外，让画框跟随鸟，或只锁定鸟的局部（头、身体等）。鸟类部位模型为实验选项，默认关闭。基本的参考区方法不依赖该模型。

播放和长按只使用较小的预览；停下后才升级清晰帧。普通模板参数的修改不会使这组成片失效；改参考区、照片顺序或源文件则会重新分析。

RAW 在这条链路里优先使用长边至少 1600 像素的内嵌 JPEG，与普通导出一致。

#### BS-14 命令行批处理

无界面命令与编辑器共用核心，适合批处理。入口为 `python -m birdstamp`（`birdstamp/cli.py`）。

- `render`：按模板裁切并叠加，输出图片。
- `gif`：把已渲染帧编成 GIF，可选微信表情版本和重复帧率。
- `stabilize`：按给定参考区域做稳定并导出。
- `recommend-regions`：建议参考区域。
- `inspect` / `inspect-auto-proxy`：查看一张照片的字段最终取自哪里。
- `init-config`：写出默认配置。
- `gui`：打开编辑器。

命令行渲染目前直接组合解码、裁切和模板叠加。与图形界面导出管线是否逐步完全一致，以 `cli.py` 的 `render` 实现为准；新增图形选项不应假定命令行已经自动具备。

#### BS-15 用户选项与更新

极速鸟框的用户选项对话框与极速鸟瞰共用同一外壳（可缩放、左侧分页、底部确定/取消）。当前产品页主要是平台安全区。许多默认行为（裁切吸附档位、GIF 默认项、去抖动缓存大小等）来自只读的 `SuperBirdStamp/config/editor_options.json`，不是每次导出都由用户重填。

折叠分组用于处理设置、导出设置、叠加属性和去抖动参数：收起只隐藏控件，不改变已经填好的数值，也不启动或停止任务。

### 共享能力

#### CM-01 应用身份、关于与外观

两款应用启动时都通过 `load_app_identity()` 得到产品名、副标题和版本，因此关于对话框和窗口标题不会各写一套版本号。关于内容（作者、链接、二维码）分别放在各应用的 `about.cfg`。极速鸟框允许用户配置目录中的 `about.cfg` 覆盖，省略图片时仍用内置图片。

系统深浅色由共享调色板和各应用自己的传播逻辑更新。选中的工具开关使用统一的蓝底白字。带标题的参数组使用可折叠分区，而不是各窗口自绘一套边框。

#### CM-02 文件浏览器

`FileListPanel` 是极速鸟瞰的主浏览器，也是极速鸟框照片列表的底层。极速鸟瞰打开了视频、快速连播、区间选择和统一后台任务；极速鸟框保持自己的列表交互，不用这套连播开关。

共用的用户动作包括：按列排序、星级/精选/排除过滤、复制剪切粘贴（含侧车）、删除到垃圾桶、在系统中显示文件、把鸟名快照复制到其他照片。评级写入 XMP。负星级表示排除。

#### CM-03 图像格式与缩略图缓存

支持的静态图片包括 JPEG、PNG、WebP、TIFF、HEIF/HEIC/HIF、PSD，以及常见相机 RAW（CR2/CR3、NEF、ARW、RW2、RAF、DNG、ORF 等，完整列表在 `app_common/image_formats.py`）。视频扩展名只由极速鸟瞰的浏览器启用。

缩略图持久档位为 128、256、512、1024、2048。缓存写在该照片自己目录或向上最多 6 层内、最近的 `.superpicky/thumb_cache/<尺寸>` 中，不要求该目录有 `report.db`。极速鸟瞰在没有缓存目录时询问是否创建；极速鸟框在照片目录自动创建，失败则改用本机缓存。两款应用可以共用 256 档。内存中的缩略图有上限，较小的缓存不能冒充后来请求的更大档位。

#### CM-04 XMP 侧车与报告库

用户编辑的标题、说明、标签、评级、精选、拍摄地点、鸟名、清晰度、连拍号等写入与照片同主文件名的 `.xmp`，使用自定义命名空间 `XMP-superpicky`，并保留与标准 XMP 兼容的标题、评级等字段。清晰度分数同时写入既有锐度字段，以便和慧眼选鸟的刻度对照。

`report.db` 只读。它用于在侧车还没有某字段时补显示，程序不创建、不迁移、不回写这个数据库。侧车里的明确值（包括数字 0 和「否」）优先于报告库。复制、移动、重命名和删除时，侧车与照片保持同名配套。

中文等非英文内容通过 UTF-8 文件交给 ExifTool 写入，而不是拼进命令行参数。

#### CM-05 预览画布、构图线与焦点几何

共享画布负责缩放、平移、构图线和把对焦点、鸟框画在正确的像素位置上。焦点居中是可选模式，两款应用共用。RAW 的焦点先映射到相机可见区域，再随当前预览来源（内嵌 JPEG、完整 RAW 或降噪图）换算，避免 A/B 两侧或快速预览用错坐标。

构图线种类见 SV-05。极速鸟瞰画在整幅预览上；极速鸟框画在裁切框内。焦点叠加若在极速鸟框中打开，会进入导出管线的焦点阶段；仅用于观看的分辨率吸附线、视频安全框和去抖动诊断框不进入成片。

#### CM-06 鸟名附属信息与连拍规则

- 拼音词表供两款应用查询，显式的 `XMP-superpicky:pinyin_name` 优先于查表。
- 稀有度和 IUCN 徽章的档位、默认颜色和用户改过的文案存在极速鸟瞰的用户配置里；极速鸟框的徽章叠加读取同一份配置，没有配置时用内置默认色。
- 复制鸟名时携带的字段见 SV-11，实现在 `bird_species_copy.py`。
- 拍摄地点字段两应用一致。
- 连拍「同一目录、按时间间隔分组、同主文件名的 RAW+JPEG 算一张」的规则在 `burst_info.py`。极速鸟瞰负责计算和显示色带；极速鸟框在模板中读取已经写好的组号和序号。

#### CM-07 应用间发送与套件更新

用户可以把当前文件发给已配置的外部程序，或发给套件中的另一个主应用。极速鸟框收到后把照片加入编辑列表。这条通道与更新器使用的通信分开。

SuperBirdUpdater 是第三个随套件安装的程序。它按公开的版本清单下载变更文件，在两个主应用都同意退出后替换安装目录中的程序文件，失败时回滚。它不修改用户照片、侧车或工作区。图片、GIF、视频正在导出时，极速鸟框拒绝为更新而退出。两个主应用的菜单都可以手动检查更新。

## 7. 后续撰写软著材料时的建议拆分

以下只是为了组织功能说明书的建议，不是登记机关是否受理、如何分类的结论。正式申请范围以主管机关的要求和代理意见为准。

建议把「极速鸟瞰」和「极速鸟框」作为两份独立软件来写功能说明，而不是合成一份无法对应到单个程序名称的说明书。

- 两者有各自的产品名、副标题、关于信息和主窗口，安装包里也是两个可分别启动的程序。
- 极速鸟瞰的说明书以第 4 节 SV-01 至 SV-20 为主线：浏览、筛选、元数据、标签、识鸟、清晰度、降噪、连拍、归档和视频。
- 极速鸟框的说明书以 BS-01 至 BS-15 为主线：导入、裁切、模板、叠加、图片/GIF/视频导出、去抖动和工作区。
- 共享库 `app_common` 不宜单独写成第三份「用户软件」，除非登记策略明确要求把库本身作为独立软件。更稳妥的写法是：在每一份说明书里，把该应用真正调用到的共享能力写成该软件的功能，并在「软件结构」中说明这些模块位于共享组件，同时被另一款配套程序使用。例如 XMP 与缩略图缓存在两份里都要写，但极速鸟瞰强调编辑和筛选，极速鸟框强调给模板和导出提供字段。
- 第 4 节的 CM 编号适合作为抽取源代码时的公共文件清单，避免两份鉴别材料各抄一遍却对不上路径。
- SuperBirdUpdater 体积和职责都小于两个主应用。若套件作为一个发行包说明，可在每一份主软件的「运行环境」里用短节描述「随套件提供的更新器」；若登记范围只覆盖某一个主程序，需要单独决定更新器是否纳入该程序的材料，本文不代替该决定。
- 清晰度、降噪在使用说明中称为实验性功能，但程序里已有完整入口和结果文件。说明书应写用户能执行的操作和产出，不必把内部阈值表整段搬入。
- 慧眼选鸟是外部配套软件。识鸟、部分模型权重和 `report.db` 依赖它的数据或本机服务。说明书里宜写成可选外部数据来源，不要写成本软件内置的鸟种识别引擎。
