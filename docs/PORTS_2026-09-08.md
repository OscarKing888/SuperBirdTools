## 适配边界

- 新标签、备注、评级和 Pick 继续使用 JSON 写入路由。优先解析最近图库 `.superpicky` 下的集中 JSON；默认 `metadata`，支持 `[sidecar] dir` 安全相对路径及旧图片旁 JSON 读取回退。没有将主分支的 XMP-only 路径替换进来。
- 标签历史用严格侧车读取识别损坏、不可读与真正不存在；写入前仍检查原图存在。XMP 兼容读取及协作日志行为保留。
- 文件操作、备注、重命名继续沿用文件写权限；标签、评级/Pick 沿用侧车权限。Viewer 的 `rating_writes_allowed()` 覆盖方法使公开评级入口也通过侧车权限检查。
- 文件列表默认仍为 `use_report_db=False`、`use_preview_cache=False`。共享库显式报告写接口未被改为全局只读。
- 正式选图的 `40 * 1024 * 1024` 像素同步完整预览阈值保持原有约定，小 HEIF 也可能进入该直接原图分支。连续方向键快速选择、RAW 嵌入预览/后台半尺寸显示和独立全分辨率覆盖导出不变。
- 同图后台更新通过局部接口更新信息并复用已解码预览；隐藏页先标记待刷新，重新激活时再局部更新。真正换图走完整刷新。
- 同目录普通重载保留本地成功编辑覆盖层；切换目录或强制重载清除，以便重新观察外部编辑。
- 本批文件事务没有改变回收策略；失败弹窗列出详情和实际保留的恢复路径。原路径被并发重建时，不以“原路径存在”作为可以删除暂存原件的依据。
