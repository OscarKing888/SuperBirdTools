# SuperViewer 照片编辑设计与实施记录

状态：功能已实现；本轮按共享库先提交、主仓集成后合并的流程交付。对应用户批准的 Camera RAW / 调色计划。

## 已确定的产品合同

- Rust 保留 PhotoCraft 算法，Python 负责共享 API、文件与状态，Qt 负责界面。
- 继续使用 rawpy 解码 RAW，首版 SDR/sRGB，16 位输入、float32 计算；不声称传感器域高光恢复。
- 两个 ImageInfoTabPanel 子类共享编辑控制器。Camera RAW 七组参数和调色十六类有序步骤。
- 编辑参数自动写原图 XMP，800 ms 去抖，支持会话内撤销/重做；不新增照片 JSON 侧车。
- 同名 RAW/JPEG 和原始/降噪底图的配方分别保存。成片保存已烘焙快照，重开不重复执行。
- 缓存可重建；降噪 TIFF 是长期资产。导出默认 edited 子目录，统一支持同目录、平级目录、固定目录、询问。
- 编辑来源与前后对比独立；A/B 各自视图、共享相同照片配方。长按导航不得启动编辑解码或 XMP I/O。
- LUT 为内容寻址资源，移动/复制照片需携带；缺失报错。原照片及 report.db 不写回。
- 库、GUI、CLI 共用完整渲染与安全导出；后台线程保留至真实结束，旧请求不得覆盖新结果。

| 层级 | 组件 | 状态与伸缩 |

| L3 页签 | ImageInfoTabPanel / ImageInfoTabWidget | Camera RAW、调色；隐藏页延迟加载 |

## 调色面板平铺分组（2026-10-14）

- L1 仍为调色信息页；L2 复用页签唯一的 `QScrollArea` 和固定底部动作。
- L3 每类调整用共享 `CollapsibleSection`，默认全部展开；L4 复用 `AdjustmentForm`，
  L5 使用独立“启用”复选框及原生菜单。顶部“全部展开／全部收起”只改变会话内显隐。
- 无配方时展示全部 16 类但均未启用；不把黑白、反相等非恒等默认值写入配方。
  启用后才能编辑参数，禁用保留数值，折叠不影响启用、撤销或保存。
- 已有步骤按真实执行顺序显示（含重复和禁用步骤），缺少的类型按目录顺序穿插为空分组。
  空分组首次启用时插入其显示位置，因此日常操作与勾选先后无关；已有配方绝不自动排序。
  每个已配置组显示步骤号；菜单保留上移、下移、复制与移除，移动只相对已配置步骤。
- 更新参数、自动保存、撤销时复用组和表单实例，保留折叠、通道、焦点及滚动位置；
  切换照片／底图按各自配方恢复，不共用业务状态。


## 一键综合自动调节（2026-10-15）

- L1 为调色页，L2 沿用单一滚动区与底部固定动作。L5 使用单个满行原生
  `QPushButton`，文案“一键自动调节”；移除三模式下拉框，无新增容器或局部 QSS。
- 共享 `photo_edit.auto_adjust.AUTO_BASIC_KINDS` 规定六个基础组：亮度／对比度、色阶、
  曲线、曝光、自然饱和度、色彩平衡。每类第一个已存步骤原位重算并保留身份，缺失组按
  调色页的可见插入规则加入；不改变已有相对顺序。额外重复步骤、Camera RAW 和风格效果保留。
- `prepare_auto_adjustment(mode="all")` 在受控 worker 中按真实步骤顺序分析，借助同一
  `render_recipe` 渲染前缀，得到当前组真正的输入，再调用 `auto_basic_parameters()`。
  缓存复用解码和 900 px 代理；估计最多采样 262144 点，处理透明／非有限像素和纯色保护。
  亮度／对比度限 ±18、−8～16；RGB 色阶保留四倍增益门限；曲线中点最多移动 0.03，
  曝光最多增加 0.35 EV、gamma 0.9～1.1；自然饱和度 −10～18；近中性色平衡最多 ±18。
  参数按表单实际单位量化，既有 Rust 渲染与 XMP 格式不变。
- 成功后 `update_editor()` 将真实参数同步给已有 `AdjustmentForm`；目标组展开，
  `show_auto_values()` 将色阶／曲线切至 RGB 总通道，色彩平衡切至中间调。
  这些视图操作不触发额外编辑／保存／撤销。无需调整的缺失组不存储恒等步骤；已有组的
  中性参数会正常显示，额外重复步骤和其他组的折叠状态保留。
- 重复点击重算相同基础组，不叠加。整次操作一次撤销、既有 800 ms XMP 自动保存。
  无照片、操作中、文件操作／导航暂停／关闭或缺少槽位时不提交；64 步上限按所有缺失
  基础组需要的槽位判断，已有六类时可原位更新。失败、取消、底图／参数变化沿用原有保护。
- CLI 默认也为 `all`；显式 `tone`／`contrast`／`color` 仅保留给旧脚本，旧 XMP 可正常加载。

```text
[全部展开] [全部收起]
```
