# 双应用统一折叠组：审查与设计

## 用户任务和布局

用户需要收起暂时不用的参数、保留输入与处理状态，并在两款应用中识别同一种折叠交互。
本轮只改变容器与布局，不改处理算法、选项默认值、元数据、导出数据或保存格式。

```text
共享 CollapsibleSection
├─ 标题：小实心三角 + 标题；整行可点、键盘可达
└─ 正文：与标题同底色、无分割线；复用原表单/列表/画布

BirdStamp 左侧：照片列表 → 处理设置 → 图片处理 / 去抖动
去抖动：1. 方式 → 2. 选区 → 3. 分析（内含原有高级匹配参数）
底部常驻：导出类型 → 可折叠导出设置 → 操作和进度
Viewer 用户选项：左侧页签 → 滚动页 → 若干语义折叠组 → 固定确认/取消
```

## 逐级选型与覆盖清单

| 应用/区域 | 层级、内容 | 选型与默认状态 | 状态和滚动 |
| --- | --- | --- | --- |
| BirdStamp 去抖动 | L3 方式、选区、分析；L4 原有表单 | 三组 `CollapsibleSection` 默认展开；匹配参数保留默认收起 | 原正文实例，沿用主设置滚动区；分析/导出业务不与折叠关联 |
| BirdStamp 模板管理 | L3 当前模板、预览、兼容文本项编辑组 | 统一折叠组，默认展开；旧文本编辑入口仍保持原隐藏策略 | 预览收起只隐藏画布，不销毁视口/会话 |
| BirdStamp 叠加层 | L3 叠加层属性、内容/布局/效果、自动行列组合 | 同级三列继续并列，组可独立折叠 | 保留输入计时器、撤销历史和元素类型显隐，正文布局用 `body` |
| BirdStamp 安全区设置 | L3 安全区组、遮挡边距、安全区预览 | 三组统一容器，默认展开 | 复用 SettingsPage；组选择/边距/参考图保持原模型 |
| Viewer 浏览与性能 | L3 加载与缓存、浏览行为、诊断；L4 网格表单 | 三组默认展开 | 同一组共用列宽，折叠不改 `selected_options()` |
| Viewer 批量降噪 | L3 输出文件、降噪处理 | 两组默认展开 | 输出方式原有联动、校验和保存不变 |
| Viewer 归档、徽章 | L3 归档规则、各徽章选项 | 复用完整表单，默认展开 | 页签与 SettingsPage 保留 |
| Viewer 鸟清晰度 | L3 清晰度参数、参数说明 | 原 AnalysisParamsForm 整体复用，说明默认收起 | 不改变参数映射、模型下载、计算流程或算法版本 |
| 共享外部应用设置 | L3 已配置的应用；L4 列表与动作 | 替代原生 GroupBox，默认展开 | 添加/编辑/删除留在列表组内；保存/取消在组外 |

原生 `QGroupBox` 构造点审查覆盖 `SuperBirdStamp/birdstamp`、`SuperViewer` 与 `app_common`。
Viewer 业务原先没有创建原生分组；`qt_compat.py` 的导出与历史样式字符串不是实际分组实例，保留兼容性。
两款应用的目录树/照片浏览器/预览画布属于导航或内容，不新增套壳。`app_common` 不依赖任一应用。

## 验证设计

共享组件检查中文输入不丢、键盘/信号、嵌套及有伸缩因子的组释放高度、启用状态与尺寸策略恢复、独立主题和字体渲染。
整合检查去抖动三组收起再展开、模板与叠加层三列、设置页取消不写文件、参数值不变、底部导出可达。
Qt5 保留导入与枚举回退；Qt6 离屏运行深浅色、可用平台样式与放大字体检查，Windows 实机结果单独说明。
