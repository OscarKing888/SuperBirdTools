# 鸟名悬停定位

- L1 用户选项沿用 SettingsDialog；L3 浏览行为沿用 CollapsibleSection；L4 对齐表单增加 L5 ColorButton，默认红色。页面滚动，确定/取消保留在滚动区外；收起不清空颜色，取消不保存。
- 图片信息沿用 TraceBirdList 的分列布局，仅逐只模式把鸟名、置信度拆为独立 QLabel；只有鸟名接收定位悬停，右键主要鸟名动作仍在鸟名上。Debug 保留整行悬停。
- A/B 工具栏移除悬停居中开关；悬停鸟名即居中，仅平移，同源视口生效。离开清框、视野不跳回，RAW 升级保持比例，长按播放不触发定位。
- 色块继续表示稀有度；预览叠加固定为空心框，颜色来自 `bird_hover_color`，默认 `#FF0000`。不写 XMP，不参与导出。

```text
浏览行为
  连续浏览速率       [24 FPS]
  切图保持缩放/位置  [勾选]
  鸟名悬停框颜色     [色块 #FF0000]  默认红色

逐只列表
  色块 编号 | 鸟名 ← 仅此处触发定位 | 稀有度 / IUCN
            | 识别置信度             | 检测信息
```

覆盖：名称/编号/徽章/置信度的独立悬停、居中不缩放、红框边线与内部像素、A/B/RAW/播放、设置保存回读/取消/重复折叠；实际离屏渲染小窗口、放大字体及深浅主题。Windows 实机未验证。
