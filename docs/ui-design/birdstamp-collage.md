# BirdStamp 拼图页

宿主为主编辑器，处理设置页签顺序：图片处理 → 去抖动 → 拼图。

```text
照片列表（原有）       │ 拼图画布工具：添加图像 overlay / 编辑叠加层 / 适应窗口
处理设置              │ 可停靠/浮动 Overlay 编辑区 │ 独立拼图预览
  图片处理 去抖动 拼图 │                           │
  ▾ 拼图排版          │                           │
    排版/成图比例     │                           │
    分辨率/宽度/高度  │                           │
    自动单格/间距     │                           │
    外边距/填充/背景  │                           │
  ▾ 拼图照片          │                           │
    加入选中/全部     │                           │
    添加文件/移除     │                           │
    素材列表与上下移  │                           │
─────────────────────│                           │
拼图导出（固定）      │                           │
  状态/进度 导出/取消 │                           │
```

- L1 页面沿用 CurrentPageTabWidget，右侧 QStackedWidget 保留照片与拼图两个宿主，切页不销毁画布。
- L2 参数统一由原左侧 QScrollArea 滚动；拼图页在窄窗口/大字体下允许横向滚动，避免主照片列表的最小宽度裁掉右侧参数，切回原页面恢复其原滚动策略。长素材列表独立滚动，ExportActionBar 操作区固定。OverlayEditorDock 保留独立属性滚动与浮动能力。
- L3 排版与照片两组使用共享 CollapsibleSection，默认展开，折叠只控制显隐。
- L4 原生 QFormLayout（窄窗口长行换行）、QListWidget、多选上移/下移；独立 PreviewWithStatusBar + EditorPreviewCanvas 共用 OverlaySession。
- L5 原生按钮/数值框/组合框及既有 ColorEditor；采用 palette 与宿主主题，不复制 QSS。

默认纵向拼图，成图为小红书竖版预设 3:4、1080 × 1440 px，间距/外边距 12 px、白底。沿用 L3「拼图排版」与 L5 原生组合框、数值框：提供 3:4、1:1、4:3、9:16、16:9、2:3、3:2 及自由比例；分辨率按短边 1080/1440/2160 提供标准/高清/超清，也可直接修改宽高。固定比例下修改一边联动另一边，自由比例可分别修改。尺寸是最终导出像素，不因照片数量或间距改变。

不再手动设置单格：宫格均分扣除边距和间距后的画布，像素余数分配到相邻格；纵向按源图高宽比、横向按宽高比分配可用长度。所有排版均支持完整显示或居中裁满，图片不拉伸；单格计算结果只读展示。照片列表是独立快照，可重复加入同一照片。超出格数明确报错，不截断照片；不足时保留空格背景。边距/间距占满画布时明确报错，禁止导出，修改参数后可恢复。渲染错误和取消状态显示在固定操作区。

宽高和比例随工作区保存。旧单格尺寸工作区先在已有 worker 中计算原成图尺寸，再迁移为自由画布，保留素材及 Overlay；不在 GUI 线程解码。CLI 默认同样为 1080 × 1440，支持直接指定宽高，旧 `--cell-size` 仍保留原有行为。

参数、素材路径、顺序、Overlay 文档由拼图控制器拥有，随工作区保存。切页、折叠、调整字体、浮动/关闭叠加面板不清空内容；不同工作区使用新的 Overlay 上下文，旧导入结果不应用到新工作区。照片和去抖动的渲染参数不变。

后台渲染/导出共用一个受所有者管理的 QThread；新参数合并为最新请求。正在导出时参数与 Overlay 禁用，取消仍可用，关闭为协作停止并等实际线程完成。预览最多 1600 px；导出按逻辑布局逐张解码并原子发布。

验证范围：真实像素、旋转和透明素材、排版边界、Overlay 预览/导出、中文路径和工作区往返、乱序结果/关闭窗口、小窗口和放大字体、深浅主题、键盘及重复折叠、固定按钮可达性。macOS 离屏验证不代表 Windows 64 位实机或打包验证。
