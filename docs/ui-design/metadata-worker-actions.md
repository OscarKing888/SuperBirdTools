# 元数据复制粘贴后台任务

宿主为共享文件浏览器和 Viewer 拍摄地点控制器。鸟名复制保留鸟名、英文名、拼音、
稀有度与地点的现有快照语义；批量粘贴和地点编辑按侧车执行，任务拥有选择快照。

组件选型：L1 非模态 `MetadataProgressDialog`；L2 原生垂直布局；L4 可滚动只读详情；
L5 原生进度条、换行状态文字和固定停止/关闭按钮。复用原地点进度的布局与 Qt palette，
无额外样式、设置、折叠组或持久化状态。窗口最小 600×380，增加高度由详情区吸收。

```text
任务名称
完成数 / 总数 · 正在处理数
[进度条]
成功数 / 失败数
[失败路径与原因；独立滚动并限制 1000 段]
[停止 → 正在停止 → 关闭]
```

任务开始时显示进度；运行中停止、Esc、关闭窗口均请求协作取消，已完成的写入保留。
真正的 QThread.finished 到达且结果排空后才释放 worker。关闭应用拒绝新任务、排空/丢弃
界面投递并等待正在执行的 action；不强行终止写入。结果只局部同步元数据，保留备注、
文件名草稿、选择和预览视野。切目录不改写新目录缓存；同侧车的已列出照片一起更新。

复制的后台结果只在请求仍为最新且系统剪贴板未被其他操作改变时提交。
紧接鸟名复制的粘贴等待新快照，不使用上一次的鸟名。所有 QWidget/剪贴板操作在 GUI 线程。

验证：共享 `test_metadata_worker_actions.py` 覆盖并发、主线程响应、同侧车去重、失败、
新旧结果、剪贴板代次、切目录、取消/退出和 Esc；既有鸟名/地点测试验证中文真实往返，
列表/缩略图同步与快捷键。离屏检查最小/常用窗口、放大字体和深浅主题的几何与截图。

2026-10-21 Windows 离屏验收：600×380、850×520、1.5 倍字体及深浅主题下，文字、
详情滚动区和停止按钮无重叠/裁切，Esc 请求停止。229 项浏览器/元数据相关回归通过，
另行通过新增的地点并发与立即粘贴测试。使用 48 张临时 JPEG、新建 XMP 和包含中文鸟名、
英文名、稀有度、IUCN、地点的同一快照，串行 action 耗时 12.203 秒，四线程协调器耗时
3.273 秒；两组共 96 个侧车回读一致。此数据仅衡量本机临时目录的写入，不含 GUI 刷新，
也不代表网络盘或所有格式的固定加速比例；未做 macOS 实机验证。
