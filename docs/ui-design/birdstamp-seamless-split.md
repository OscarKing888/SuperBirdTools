# BirdStamp 连屏切图

处理设置中与图片处理、去抖动、拼图并列。单张源照片的横向等分；每张比例决定总裁剪比例（份数 × 单张宽高比）。普通裁剪和连屏裁剪各自保存。

```text
照片列表              │ 整体裁剪 / 逐张预览
图片处理 去抖动 拼图 连屏切图
  ▾ 切分设置          │ 调整裁剪框 / 分割线 / 编号 / 适应 / 100% / 缩放
    份数、每张比例    │
    分辨率、宽高      │ EditorPreviewCanvas 独立派生画布
  ▾ 构图设置          │ 整体：源图 + 总裁剪框 + 等距线
    裁满/完整补边     │ 逐张：成片切片 + 上一张/下一张
    背景、重置、撤销  │
  ▾ 输出设置          │
──────────────────────│
状态/进度/导出/取消（固定）
```

- L1 沿用 CurrentPageTabWidget 与右侧 QStackedWidget；独立控制器持有参数、逐图裁剪和后台 worker，切页不销毁。
- L2 左侧主 QScrollArea 统一滚动，窄窗口允许横向滚动；ExportActionBar 固定动作。工具栏按两行排列，原生布局可伸缩。
- L3 三组 CollapsibleSection 默认展开；折叠不修改参数、不触发解码。
- L4 PreviewWithStatusBar + SplitPreviewCanvas 复用 EditorPreviewCanvas 的比例裁剪与坐标；分割线和编号仅绘制到视口。ImageOutputOptionsForm 复用五种目录语义；PNG 标签明确本功能为 8 位输出。
- L5 原生组合框、数值框、ColorEditor、ToggleToolButton；整体/逐张互斥，独立布尔工具。深浅主题来自 palette，不新增 QSS。

默认 3 张、每张 3:4、1080×1440、裁满、JPEG 质量 95。份数 2–20，单边 64–8192，总画布不超过 100 MP，非法组合显示原因且禁用导出。完整显示模式保留全图并补边，不提供裁剪拖动；切回裁满恢复原构图。比例/份数改变尽量保留中心和面积；拖动在源图内约束，不延伸到不可见区域。单次手势只记一条撤销，逐图历史仅在会话内保存。

每张图保存独立裁剪框，全局份数/比例/尺寸/输出与显示开关随工作区保存；路径使用现有相对路径序列化。切页结束拖动、停止播放；连屏不接管其他页面的 A/B 和普通裁剪。预览焦点内左右键仅切换切片。输入为源照片，不隐式套用模板或去抖动结果。

核心由无 Qt 的 SplitOptions / SplitCanvasStage / SplitExportStage 实现，GUI 与 CLI 共用。预览后台有界解码，导出只使用完整源图；总画布统一采样后按整数边界切片。独立管线不注册到普通图片/GIF/视频的阶段列表；无帧缓存。导出固定元数据快照，调用现有 save_export_image 保存 EXIF/ICC 与独立 XMP。整个临时目录有即时所有权；完成后发布到新的、不重名的结果目录，不覆盖既有整组。

后台单 worker + 最新待处理请求，版本与 worker 身份过滤迟到结果，真实 finished 后才交接。导出时参数/构图冻结，切页可继续，取消可达；工作区切换取消旧任务并丢弃旧结果。关闭协作取消并等待实际线程退出。

验证：拼回 PNG 与总画布逐像素一致；奇数像素、各种比例、补边、透明/旋转、无效尺寸；中文 XMP 读回和原图不变；取消/失败与重名发布；工作区往返、切图、真实拖动、键盘、迟到结果和关闭；小窗口/放大字体/深浅色实际离屏截图。CLI 同核心入口。

## 使用

在照片列表选择图片，切换「连屏切图」，设置份数和每张宽高。整体裁剪中拖动框和手柄调整构图；逐张预览中使用上一张/下一张或画布焦点内的左右键检查。裁满和完整补边共用同一总画布规则，完整补边时不启用裁剪拖动。分割线与编号不会导出。导出到所选目录下的 `原名_连屏`，重名自动编号；组内为 `原名_01.jpg` / `原名_01.xmp` 等。

从 `SuperBirdStamp` 目录使用仓库虚拟环境的解释器，可运行 `python -m birdstamp split photo.jpg --output out --count 3 --width 1080 --height 1440 --format png`。`--crop left,top,right,bottom` 接收源图归一化总裁剪框，`--fit contain` 保留完整照片并补边，`--background` 设置背景。GUI/CLI 都拒绝超过上限的总画布，不静默降低导出尺寸。
