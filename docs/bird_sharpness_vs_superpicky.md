# 鸟清晰度检测与 SuperPicky 锐度算法对比

本文比较本仓库的鸟清晰度检测（[算法说明](bird_sharpness.md)）与 [SuperPicky（慧眼选鸟）](https://github.com/jamesphotography/SuperPicky) 的头部锐度算法。SuperPicky 一侧依据其源码 `core/keypoint_detector.py`、`core/photo_processor.py`、`core/rating_engine.py`（对比时的版本为 `fe50631`）。

两者目标不同：SuperPicky 的锐度是整套选片评星的一个输入，与美学、曝光、飞行、眼的可见度一起决定星级；本仓库只回答「鸟本身清不清晰」这一个问题。下面的比较只针对这一个问题。

## 相同之处

- **模型**：使用同一个鸟体分割模型 `yolo11l-seg.pt` 和同一个鸟眼/鸟喙模型 `cub200_keypoint_resnet50_slim.pth`（本仓库运行时读取已安装 SuperPicky 中的文件，见[根目录 README](../README.md#鸟识别模型与-superpicky)）。
- **头部区域**：以眼为圆心、眼到喙距离的 1.2 倍为半径画圆，再与鸟体分割掩膜取交集；看不到喙时都用鸟框的 15% 作半径。

区别在于从这块像素得出清晰度的方式。

## 主要区别

| | SuperPicky | 本仓库 |
| --- | --- | --- |
| 输入图像 | RAW 内嵌的相机 JPEG（经机内锐化、降噪、8 位压缩） | LibRaw 解码 RAW 原始数据，不做锐化 |
| 测量方法 | Tenengrad：头部区域 Sobel 梯度平方的均值，按对数映射到 0–1000 | 只取头部区域最强的 5% 边缘，用二次模糊比值法测边缘模糊半径 σ（单位：像素），再映射到同一 0–1000 刻度 |
| 影响数值的因素 | 反差、羽毛纹理、噪点、机内锐化、鸟的大小；为此另有高 ISO 打折（ISO 800 起每翻倍扣 5%）和小区域扣分两项补偿 | 边缘模糊半径与反差无关；比噪声强不到 4 倍的边缘、细枝等线状结构不参与测量 |
| 运动模糊 | 不单独区分 | 按 8 个方向比较身体模糊程度，单独判为「运动模糊」 |
| 看不到眼 | 仍计算，分数乘 0.8；眼和喙都看不到时直接 1 星 | 判为「无鸟眼」，分数上限 299 |
| 多只鸟 | 计算主要的一只 | 每只单独计算，取最好的一只 |
| 没有识别到鸟 | 不计算锐度 | 依次复检伪装/遮挡的鸟 → 焦点区域 → 全图 |
| 相机焦点 | 按焦点落在头部 / 鸟身 / 鸟框内 / 框外给锐度权重 1.1 / 1.0 / 0.7 / 0.5 | 用于复检被漏掉的鸟和无鸟时定位测量区域，不参与打分 |
| 结果范围 | 星级还结合美学评分、曝光、飞行、眼的可见度 | 只输出清晰度判定、分数与 σ |

## 实测对比

对 2026-10-02 世纪公园同一批人工判定过的 15 张照片（ISO 1600–8000），按 SuperPicky 的流程（内嵌 JPEG → 分割 → 鸟眼 → Tenengrad → ISO 补偿）和本仓库算法分别计算：

| 照片 | 人工判定 | SuperPicky 锐度（含 ISO 补偿） | 本仓库 |
| --- | --- | --- | --- |
| DSC04684 / 04516 / 04678 / 04512 / 04769 / 04514 / 04739 | 清晰 | 431 / 444 / 373 / 441 / 490 / 411 / 330 | σ 0.58–0.83，均判清晰 |
| DSC04674 | 可用 | 469 | σ 0.89，判可用 |
| DSC04393 / 04395 / 04392 | 失焦 | 442 / 441 / 411 | σ 1.25 / 1.29 / 1.70，判失焦 |
| DSC04752 / 04757 | 失焦 | 230 / 200 | 判失焦 |
| DSC05009 | 运动模糊 | 492 | σ 1.41，判运动模糊 |
| DSC04385 | 运动模糊 | 0 | 判运动模糊 |

- **区分能力**：任取一张清晰、一张不清晰的照片，SuperPicky 的数值把清晰那张排在前面的比例为 61%（随机水平为 50%），本仓库为 100%。
- **按 SuperPicky 默认门槛 400**：14 张（不含「可用」）中判对 8 张；门槛取 350 或 450 时判对 9 张或 7 张。原因不在门槛取值：这批照片中失焦图与清晰图的数值区间重叠，任何单一门槛都无法分开。

## 差异的原因

- **梯度均值反映「强边缘多少」，不是「边缘多锐」**：花纹反差大的羽毛即使失焦，梯度仍然高；清晰但羽色平淡的鸟反而偏低。
- **机内锐化**：相机 JPEG 会把模糊的边缘重新锐化，Tenengrad 读到的数值随之升高；本仓库测 RAW，不受影响。
- **高 ISO 噪点**：噪点抬高梯度均值。SuperPicky 按 ISO 统一折算，本仓库逐条边缘判断是否明显强于噪声。
- **运动模糊**：沿运动方向的边缘仍然清楚，梯度均值可以很高（DSC05009）；按方向比较模糊程度才能识别。
- **单位**：σ 以像素为单位，门槛有明确的物理含义；Tenengrad 数值会随机型、画面风格设置而变化。

## SuperPicky 的长处

- **速度快**：读取内嵌 JPEG；本仓库每张需完整解码 RAW，约 1–2 秒。
- **相机焦点权重**：焦点不在鸟上时直接降分，是很有价值的先验，本仓库目前未用于打分。
- **完整的选片流程**：美学、曝光、飞行、眼的可见度一起决定星级。
- **使用面广**：经过多种相机和大量用户的实际使用。

## 局限与后续

- 样本只有 15 张，来自同一次拍摄、同一台相机。
- 本仓库的阈值正是在这批照片上标定的，100% 属于样本内结果，偏乐观；SuperPicky 的数值区间重叠则与阈值无关。
- 要得出更可靠的结论，需要在其他相机、焦段和光线条件下各标注几十张再做对比。
